# Kee Phillips Portfolio Site

This folder is a privacy-safe GitHub Pages portfolio starter for the ITS4103 Week 5 website.

## Included now
- `index.html` - Home page, attributes, career direction, elevator pitch text
- `resume.html` - Public resume with personal phone, email, and home address removed
- `cover-letter.html` - Generic software development cover letter
- `contact.html` - LinkedIn and GitHub professional contact options
- `style.css` - Shared responsive styling
- `media/` - Folder reserved for the Week 5 elevator-pitch audio

## Not included yet
Portfolio/project pages are intentionally omitted for now. They can be added later without changing the current pages.

## Publish to the existing GitHub Pages repository
Repository: `kphillips85/Kee-s-Resume`

1. Download and unzip this package.
2. In GitHub, open the `Kee-s-Resume` repository.
3. Back up your current `index.html` first if you want to preserve it.
4. Upload or replace these files in the repository root:
   - `index.html`
   - `resume.html`
   - `cover-letter.html`
   - `contact.html`
   - `style.css`
5. Upload the `media` folder as well.
6. Commit the changes.
7. Wait a minute or two for GitHub Pages to redeploy.
8. Open: `https://kphillips85.github.io/Kee-s-Resume/`
9. Test every navigation link on desktop and mobile.

## Add the elevator pitch audio later
1. Record the final elevator pitch as an MP3.
2. Name it `elevator-pitch.mp3`.
3. Upload it into the `media` folder.
4. Open `index.html`.
5. Find the comment labeled `Week 5 audio requirement`.
6. Remove the HTML comment markers around the audio block.
7. Commit the change and test the audio player on the live site.

## Add projects later
When ready, add `portfolio.html` and individual project pages, then add a Portfolio link to the navigation on all four current pages.
